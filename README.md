## 🧠 How I work

| | |
|---|---|
| 🔍 **Start from the user** | Frame the problem with real context, separate facts from assumptions, scope the MVP to one decision |
| 🏗️ **Ship end to end** | Schema → API → UI → deploy, with queues, auth and payments where the problem needs them |
| 📏 **Measure it** | Latency percentiles, Lighthouse and axe scores, forecast metrics: claims come with numbers |
| 🤝 **Humans in the loop** | AI drafts and ranks; people approve and decide |
